# Property_Selling_Website
🏠 Property Selling Website  A full-stack real estate platform built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). The platform allows users to explore properties, search and filter listings, view property details, and manage property listings through a user-friendly and responsive interface.
<br/> <br/>
<b>🚀 Tech Stack </b><br/>
Frontend: React.js <br/>
Backend: Node.js, Express.js <br/>
Database: MongoDB <br/>
Authentication: JWT <br/>
Styling: CSS / Bootstrap <br/>
API: RESTful APIs <br/> <br/>
<b>✨ Key Features </b> <br/>
User registration and login <br/>
Property listing and management <br/>
Property search and filtering <br/>
Detailed property information <br/>
Responsive and user-friendly UI <br/>
Secure backend APIs <br/>
MongoDB-based data management
